# Skills

Lors de l’installation d’un skill, récupérer les fichiers nécessaires à son fonctionnement ou adapter leurs liens, puis vérifier que toutes les références sont accessibles.

| Skill | Usage | État |
|---|---|---|
| [code-style-fix](code-style-fix/SKILL.md) | Corrections de style et d’organisation ; branche ou projet complet. | Préparé, à essayer |

Les rapports HTML font partie des livrables des opérations concernées, sans skill séparé.
Les skills fournis par les plugins restent gérés par leurs plugins.
