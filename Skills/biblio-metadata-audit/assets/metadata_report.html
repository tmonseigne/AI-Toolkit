L'inventaire contient toutes les notices actives, hors corbeille, notes et pièces jointes. L'analyse des champs porte sur les articles ; les autres types sont inclus pour le contrôle des doublons.

Vérifié : valeur contrôlée sur une source primaire et consignée dans le suivi. Les rapprochements automatiques restent des propositions. Proposition : changement à relire, notamment noms complets, identités candidates et titre officiel des revues. À vérifier : identité ou information non résolue. Manquant : champ vide, parfois légitimement absent. Les rapprochements avec d'autres notices locales sont explicitement des propositions à confirmer. Un prénom complet suivi d'une ou plusieurs initiales intermédiaires est accepté (par exemple « Paul A. »), ainsi qu'un prénom complet seul. Les initiales en tête du prénom, les prénoms absents et les problèmes d'encodage restent signalés. Les formes d’usage officiel avec une initiale suivie d’un prénom sont également acceptées lorsque la source les confirme. Les auteurs collectifs sont conservés.

Les dates brutes de Zotero combinent une composante de tri et le texte saisi : les jours/mois 00 et les répétitions ne sont pas, à eux seuls, des erreurs de saisie. Un numéro ou une pagination peut être absent pour une revue à publication continue ; un numéro d'article peut occuper le champ pages. Les noms historiques des revues doivent être conservés.

Les fichiers JSON conservent l'avant/après et les sources. Ils constituent un plan de correction, sans import automatique ni fichier BibTeX risquant de créer des doublons.
